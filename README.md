# From Survival Mode to Sustainable Practice

Toolkit from the ACGME Annual Educational Conference 2027 session on designing a well-rounded onboarding experience for new GME program administrators. Presented by Amy Rosa, Barbara Gohre, and Beth Smith.

Site: https://bgohre.github.io/sustainable-practice-toolkit/

What is here
- `index.html`: the toolkit site. Twelve fillable worksheets and tools that save in the visitor's browser, with CSV, Markdown, and JSON export.
- `files/Onboarding_Worksheet_Handout.docx`: the five-worksheet handout.
- `files/Onboarding_Roadmap_Tracker.xlsx`: eight-sheet Excel tracker.

Free, editable, and open access. Add your own logo, change any wording, and adapt every worksheet to your own policies and division of responsibility. This is a framework, not an accreditation requirement.
